💱 Currency Bot
Telegram-бот для моніторингу курсу валют Національного банку України. Показує актуальні курси, конвертує суми між валютами, веде журнал історії та сповіщає про досягнення цільового курсу.
🛠 Технології
Python 3.11+
aiogram 3.x — Telegram Bot API
aiosqlite — асинхронна робота з SQLite
APScheduler — фонові задачі за розкладом
aiohttp — запити до API НБУ
tenacity — автоматичні повторні спроби при збоях мережі
matplotlib — побудова графіків історії курсу
pydantic-settings — конфігурація через `.env`
pytest / pytest-asyncio — автотести
✨ Функціонал
📊 Курс 5 валют до гривні (USD, EUR, PLN, GBP, CHF) з індикатором зміни (📈/📉/➖)
🔄 Двосторонній конвертер між будь-якими з 6 валют (UAH, USD, EUR, PLN, GBP, CHF)
🔔 Одноразові підписки на сповіщення при досягненні цільового курсу
📈 Графіки історії курсу за 7/14/30 днів
📋 Перегляд і скасування власних підписок (з inline-кнопками)
🔍 Inline-режим (виклик бота прямо з будь-якого чату)
⌨️ Зручне кнопкове меню
🛡 Захист від спаму командами (throttling)
📝 Логування в файл з автоматичною ротацією
💬 Команди
Команда	Опис
`/start`, `/menu`	Головне меню з кнопками
`/rate`	Поточний курс усіх валют
`/convert <сума> <валюта>`	Конвертація в гривню (напр. `/convert 100 usd`)
`/convert <сума> <з> <у>`	Конвертація між будь-якими валютами (напр. `/convert 100 usd eur`)
`/subscribe <валюта> <умова> <курс>`	Підписка на сповіщення (напр. `/subscribe usd > 41.5`)
`/mysubs`	Список активних підписок
`/unsubscribe`	Скасувати підписку (покаже кнопки вибору)
`/history <валюта> <дні>`	Графік історії курсу (напр. `/history pln 14`)
`/help`	Довідка по всіх командах

🚀 Встановлення
```bash
git clone https://github.com/GreedyClark/currency-bot.git
cd currency-bot

python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
```
Створи файл `.env` на основі `.env.example`:
```
BOT_TOKEN=твій_токен_від_BotFather
DB_PATH=database/currency.db
```
Запуск:
```bash
python bot.py
```
При першому запуску бот автоматично створить базу даних і завантажить історію курсів за останні 30 днів.
🤖 Налаштування BotFather
Щоб команди показувались підказками в Telegram, встанови їх через @BotFather командою `/setcommands`:
```
start - Почати роботу з ботом
menu - Головне меню
rate - Поточний курс валют
convert - Конвертувати суму
subscribe - Підписка на сповіщення
mysubs - Мої активні підписки
unsubscribe - Скасувати підписку
history - Графік історії курсу
help - Довідка по командах
```
⚙️ Як це працює всередині
Планувальник (APScheduler): щогодини перевіряє активні підписки; о 18:00 щодня зберігає поточні курси в історію
Backfill: при першому запуску на порожній базі підвантажує історію курсів НБУ за 30 днів
Retry: мережеві запити до НБУ автоматично повторюються до 3 разів при короткочасних збоях
Throttling: команди від одного користувача обробляються не частіше ніж раз на 1.5 секунди
✅ Тести
```bash
pytest
```
Тести покривають роботу з базою даних (дублікати підписок, upsert історії курсів) і логіку конвертації. Мережевих запитів під час тестів не виконується — використовується тимчасова ізольована база.
